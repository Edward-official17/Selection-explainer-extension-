# Selection Explainer for Gemini

⚠️ **Disclaimer:** This is an independent, unofficial project developed by EDCORP STUDIO. It is not affiliated with, endorsed by, or connected to Google LLC or Gemini in any way.

🚀 An independent browser extension that helps you analyze, summarize, and understand any selected text using Gemini AI. Perfect for reading long articles and learning new topics! 💡

## 🔑 API Key Required
To use this extension, **you need to provide your own Gemini API key**. 
* The extension connects directly to the Gemini API.
* Your API key is stored safely locally in your browser and is never shared with anyone.

## 🛠 Installation
1. Download this repository as a ZIP file and unpack it.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** (top-left button) and select the `dist` folder.
5. Open the extension popup, paste your Gemini API key, and start using it!
